# Identidade visual

- Marca: Doc Motor.
- Logo oficial retangular: `public/assets/brand/doc-motor-logo-retangular.png`; usar em cabeçalho, rodapé e futuras telas de login/painéis.
- Ícone oficial quadrado: `public/assets/brand/doc-motor-icone.png`; usado como fonte dos favicons e ícones PWA em `public/icons/`.
- Os arquivos oficiais foram apenas copiados e redimensionados para os tamanhos técnicos exigidos; a marca não foi redesenhada.
- Paleta: vermelho comercial `#d9282f`, preto `#181818`, branco, cinza papel `#f3f3f0`; azul do arquivo oficial permanece na marca.
- Tipografia: Manrope para interface e DM Mono para microtextos técnicos.
- Direção: premium, automotiva, técnica e legível; usar imagens com textura real, contraste e espaço para conteúdo.
- Evitar excesso de gradientes, cards arredondados, emojis como elementos e animações pesadas.

## Fase 1.4

O proprietário aprovou visualmente a página comercial publicada e solicitou somente a substituição da identidade visual pelos arquivos oficiais retangular e quadrado.
