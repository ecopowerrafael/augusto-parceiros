# Identidade visual

- Marca: Doc Motor.
- Logo oficial: `public/assets/logo.png`, fornecida no diretório do projeto; não redesenhar sem autorização.
- Paleta: vermelho comercial `#d9282f`, preto `#181818`, branco, cinza papel `#f3f3f0`; azul do arquivo oficial permanece na marca.
- Tipografia: Manrope para interface e DM Mono para microtextos técnicos.
- Direção: premium, automotiva, técnica e legível; usar imagens com textura real, contraste e espaço para conteúdo.
- Evitar excesso de gradientes, cards arredondados, emojis como elementos e animações pesadas.
